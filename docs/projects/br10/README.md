# br10 — «Весь веб в одном компьютере» (как работает браузер и откуда он взялся), 56,6 с

Сборка: озвучка `pauses.py` (сжатие пауз в тишине + темп 1,07 rubberband) → 3D-слои `3d/` (Three.js в headless Chrome через puppeteer-core, `node drive.mjs jobs.json`, прозрачные PNG) → композит `r.py` (Pillow, 25 fps, FFV1) → звук `mix.py` → экспорт H.264 10 Мбит/с.

Хук 0–5,6 с: прыжок сквозь глобус из ссылок, вспышка, аватар в окне браузера, его цветные копии каскадом окон; на «в одном компьютере» веб схлопывается в чёрный куб NeXT, на «Не выключать!» шлёпается записка. Аватар не перекрыт текстом, субтитры под карточкой.

Палитра «веба»: ссылка циан #39D5FF, сигнал янтарь #FFB23E, пакеты/код зелёный #4DFFA6, сервер/тревога маджента #FF4F8B; ретро-окна серые 90-х. Субтитры белые с обводкой, ключевые слова #FFD34D.

Аватар: один клип HeyGen на начало (0–5,6 с) и конец (50,55–56,6 с).
