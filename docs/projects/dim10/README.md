# dim10 — «Ты видишь только 2D» (измерения), 58,2 с

Сборка: озвучка `pauses.py` (сжатие пауз в тишине + темп 1,06 rubberband) → 3D-слои `3d/` (Three.js в headless Chrome через puppeteer-core, `node drive.mjs jobs.json`, прозрачные PNG) → композит `r.py` (Pillow, 25 fps, FFV1) → звук `mix.py` → экспорт H.264 10 Мбит/с.

Дизайн: у каждого измерения свой цвет (0D белый, 1D голубой, 2D фиолетово-синий, 3D янтарный, 4D розово-малиновый, время бирюзовый, 5D+ лиловый); субтитры Unbounded ExtraBold с подсветкой ключевого слова цветом его измерения, HUD как в wh10 v2 (MB + тема + таймер + прогресс цвета текущего измерения).

Аватар: один клип HeyGen Avatar V на начало (0–3,58 с, сначала на весь экран с обложкой, затем карточка) и конец (52,9–58,2 с, карточка).
