# dim10: источники футажа и звука

## Видео
- NASA Image and Video Library (public domain по NASA media guidelines), в ролике использованы:
  - «Earth Views from the International Space Station» (nv00, 48–50,7 с) — Земля с МКС;
  - GSFC_20181002_SMBH_m13043_Simulation (nv04, 40–44,3 с) — симуляция двух сверхмассивных чёрных дыр (кадр «Калуца»);
  - GSFC_20181108_FERMI_m13042_Luck4K (nv05, 24,5–28,8 с — слияние нейтронных звёзд, гравитация + свет; 15–18,1 с — купол обсерватории под звёздами).
  Остальные скачанные ролики (footage.json) не вошли.
- Кадр «5D-кино» (капли воды и экран) нарисован кодом: клип со шлангом с Commons скачать не удалось.
- 3D-графика (точка→тессеракт, сетчатка, пространство-время, шланг Калуцы–Клейна, сечение Калаби–Яу) — Three.js, рендер кодом для ролика.
