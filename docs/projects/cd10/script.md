# cd10 — рисование кодом против нейрогенерации (40–50 с)

[аватар] Нейросеть рисует пикселями. А код — формулами. Смотри, что будет при зуме.
Слева — каша из квадратиков. Справа — ни одной размытой линии.
Нейросеть вроде Stable Diffusion начинает с шума. И шаг за шагом убирает лишнее, пока по твоему описанию не проявится картинка. На выходе — миллион цветных точек.
А Claude Code пишет не точки, а инструкцию: круг, радиус сто двадцать, цвет жёлтый. Браузер читает её и рисует хоть на билборд.
Теперь правки. Хочешь голубую луну? Нейросеть часто перерисует всё, и горы уже другие. А в коде меняешь одну строчку. Остальное на месте.
Добавил в формулу время — и картинка ожила.
Зато лицо или фото нейросеть нарисует лучше. Она — фотограф. Код — чертёжник.
[аватар] Кстати, всё в этом ролике нарисовано кодом. Кроме меня. Наверное.
