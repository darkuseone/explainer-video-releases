- Первая фраза: называет SpaceX, Техас, здания и причину смотреть (электричество целого города).
- Цепочка: здания → что это → зачем ракетной компании → сколько энергии → образ → откуда энергия → тепло и охлаждение → ирония → вывод → вопрос.
