# dc10 — ударения (дубль B)
Разметка: ruaccent + ручная правка (U+0301; Недалеко́ исправлено, у ruaccent было «недалёко»). Проверка: forced alignment wav2vec2-xlsr-53-russian + фонемная модель xlsr-53-espeak.

## Не подтверждено автоматически (на слух не проверено)
- «подала» — безударная «о» в первом слоге не редуцирована (возможен вариант «по́дала»).
- «городу» — безударная «о» не редуцирована.
- «разом», «местного», «центров», «компьютеров» — «о» в окончании, вероятно артефакт фонемной модели.
- «Грок» — ASR слышит «GROG» (звонкость конечного согласного, ударение одно).
- Слова, где гласные различаются только и/у/ы, этим методом не проверяются.
Строки «по просодии слог N» — расхождение пика просодии с ударным слогом; на клипе ASR слова распознаны корректно.
